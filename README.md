# Прогнозирование соотношения матрица/наполнитель

Приложение позволяет решать задачу прогнозирования "Соотношение матрица/наполнитель".

## Инструкция по использованию

### Шаг 1. Запуск приложения
1. Убедитесь, что установлены необходимые библиотеки (`pip install streamlit`).
2. Запустите приложение через терминал вашей ОС:  
   ```bash
   streamlit run app.py
   ```
3. Приложение автоматически откроется в вашем браузере по адресу http://localhost:8501.

### Шаг 2. Ввод параметров
1. В центре экрана найдите блоки ввода с 12 параметрами композитного материала и его компонентов.
2. Введите числовые значения в соответствии с вашими данными.

### Шаг 3. Получение результата
1. Нажмите кнопку **«Рассчитать»**.
2. На экране отобразится Рекомендуемое соотношение матрица-наполнитель.
